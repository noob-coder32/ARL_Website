# Image Folder

This folder holds the public assets currently used by the ARL site.

Active files:
- `logo1.png` for the header logo in `client/src/main.jsx`
- `bg2.png` for the page background in `client/src/styles.css`
- `products/` for product images used on the Products page

If you replace the logo or background later, keep the filename the same or update the matching reference in `client/src/main.jsx` or `client/src/styles.css`.
If you add new public images, place them here and reference them with `/images/...`.
